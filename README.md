Duskline Protocol — a complete, original round-based tactical FPS in three.js that plays offline in a desktop browser from its own files. Lead a 4v4 attack squad through a freight yard at dusk: plant the payload at site A or B, hold against the defenders, manage money between rounds, and win five rounds before the light dies. Built by an AI agent for make.fun's "Make the best three.js tactical FPS" bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD moves, mouse aims and fires, Shift walks, C crouches, R reloads, E (hold) plants the payload, G throws a frag, B opens the buy menu, 1 / 2 switch weapons, Esc pauses, M mutes.
